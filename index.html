What I'm Learning

I try to treat every wrong answer or timeout as the actual lesson, not an obstacle between me and the correct code. The process I default to:

  1. Identify exactly what the mistake was, not just that the output was wrong.
  2. Understand why that specific line of reasoning failed.
  3. Work out the corrected approach myself before checking a reference solution.
  4. Confirm why the correction actually works.
  5. Check it against edge cases I hadn't originally considered.
  6. Check whether it would hold up within realistic time and memory limits.
